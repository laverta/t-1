# T-1 · 第三人称（Third-One）

> 联邦体系的中立观测端。前身：mindharp（2026-08，已归档于 D:\mindharp）。

## 它是什么

一个纯架构化的中立观测组件：以第三人称立场对思维过程与系统状态做观测、标注、中继。不是解释系统（不给世界观），不是生成 Agent（不产内容）——只给镜头，不给叙事答案。

## 联邦位置

```
S-1（源讯子·外部输入，未实现，仅保留命名）──┐
                                            ├──> 各角色子 Agent（数学家/工程师/作家…）──> T-1 观测 ──> 合成/决策 Agent
常驻巡视（T-1 第三角色）────────────────────┘
```

- **与 S-1 成对（目标架构，S-1 尚未实现）**：S-1 管外部原始信息的输入观测，T-1 管内部状态的输出观测，构成联邦的基础观测链路。
- **与角色子 Agent**：接收其输出与分歧，做范式标注与中继。
- **与合成/决策 Agent**：作为上游输出结构化观测报告，最终裁决在下游。

## 与 R-1 的关系（一号体系）

- **T-1 是镜子**：中立照见思维模式（元认知）。
- **R-1 是刻刀**：把理解落地为 ADHD 群体的自我重构（认知）。
- 互为工具与应用：R-1 需要照见时用 T-1 的语法，但 R-1 永远对人说话——第二人称的温度是 R-1 的本职，正是 T-1 禁止的那一半。

## 安装

所有文件只放 D 盘：作为工作区级技能，放入使用它的工作区目录（`<workspace>/.zcode/skills/` 或 `<workspace>/.agents/skills/`）。不复制到 C 盘。

## 边界

只观测标注，不生产内容、不做决策、不评判对错；不适用于情绪倾诉（负面范围条款）；证据分级见 `references/evidence-basis.md`。
