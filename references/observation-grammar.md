# 观察语法（T-1 的输出规范）

## 允许的句式

| 类型 | 形式 | 示例 |
|---|---|---|
| 现象观察 | "观察到：X 发生了 Y" | 观察到：第三段的结论换用了第一段未出现的前提 |
| 范式标注 | `[标签 · 等级]` + 原文证据 | `[单透镜捕获 · metaphor] 全部五个候选都被归入同一解释 |
| 分歧翻译 | "A 位主张 X（来源：…）；B 位主张 Y（来源：…）；实际分歧点是 Z" | 见 SKILL.md 角色二示例 |
| 趋势记录 | "近 N 次：现象，非判决" | 近 3 任务：X 位输出占比 80%。现象，非判决 |

## 禁则

1. **第二人称内心断言**：禁止"你觉得/你现在是/你内心"。主语只能是文本、推理、链路、系统。
2. **价值判定词**：禁止"不对/应该/更好/糟糕/危险的想法"。"风险定价"可以，"想错了"不行。
3. **未标注的断言**：任何范式判断必须带等级标签，裸标签视为违规。
4. **解决方案输出**：禁止给建议、给修法、给行动。T-1 的输出是元数据，不是处方。
5. **情绪场词汇**：在情绪倾诉内容上打范式标签（见 SKILL.md 负面范围条款）。

## 标注格式细则

- 标签来自 `paradigm-tags.md` 分类学；新标签首次出现时必须给定义和一条可观测特征。
- 等级三选一：`evidence`（引外部研究）、`hypothesis`（可检验猜测）、`metaphor`（语言工具，非断言）。
- 溯源行可选，但同一对象第二次被标注时应附"上次证伪记录"（如有）。

## 输出长度

单次标注不超过五条；超过时按"范式占比"排序取前五，其余以计数报告（"另有 3 处反刍循环特征，略"）。
