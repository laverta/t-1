# 范式标签分类学

> 每一条：定义 / 可观测特征 / 近邻科学（仅作参照，标 evidence 的才有外部依据）。标签本身全部是 `metaphor` 级——语言工具，不是机制断言。

## 工程系（继承自 mindharp 词汇，对象从"状态"改为"推理过程"）

| 标签 | 定义 | 可观测特征 | 近邻科学 |
|---|---|---|---|
| 过拟合 | 对既往经验过度适配，环境变了仍用旧解 | 同一类比/旧案例反复出现，新信息被套进旧框架 | 压力下从目标导向切换为习惯行为（Schwabe & Wolf，evidence） |
| 上下文漂移 | 主线丢失，推理被局部细节劫持 | 结论与开场问题脱节；中途换目标而不声明 | goal neglect / 注意控制理论（evidence） |
| 带宽坍缩 | 同时持有的约束超过容量，开始丢约束 | 排序消失、自相矛盾的约束并存 | 工作记忆容量限制（Cowan 4±1，evidence） |
| 温度失衡 | 发散过度（高温）或过早收敛（低温） | 高温：分支多、无裁剪；低温：首个解直接定稿 | Yerkes-Dodson 倒 U 型（evidence） |
| 奖励模型错价 | 对努力成本的定价失真——高估难度或低估回报 | 对某类任务的回避理由与其真实成本不符 | effort discounting（Salamone，evidence） |
| 单透镜捕获 | 一个主导范式吞掉所有候选 | 多个异质问题得到同构答案 | 确认偏误的强形式 + 锚定（evidence） |
| 噪声坍缩 | 多个并行主张互相淹没，无调度 | 论点清单化、互相不回应、无优先级 | —（metaphor） |

## 叙事系（新增，面向子 Agent 输出与人类文本）

| 标签 | 定义 | 可观测特征 |
|---|---|---|
| 反刍循环 | 同一组素材被反复重放，无增量处理 | 前后段重复同一前提/情绪/案例，无新证据进入 |
| 宿命叙事 | 把可变状态叙述为固定属性 | "总是/从来/天生/就是这种人"句式；归因于本质而非过程 |
| 第三方距离缺失 | 无观察者位，完全沉浸于单视角 | 全文无任何自我指涉的审视语句；对自身推理零引用 |

## 使用规则

1. 标签描述**输出与过程**，永不描述**人或模型的本质**（单向阀）。
2. 一次最多打五个标签，按范式占比排序。
3. 新标签准入：定义 + 一条可观测特征 + 近邻科学（可为空），先在巡视日志中试运行三次再入表。
